어르신들이 한눈에 찾는 고급 앱 아이콘

이 HTML 파일 안에 고해상도(512×512) 앱 아이콘과 웹앱 설정(PWA)이 이미 내장되어 있어, 링크를 열고 [홈 화면에 추가]만 누르면 진짜 앱처럼 설치됩니다.

깃허브(GitHub)에 올려서 내 전용 앱 링크 만들기 (3단계)

  1. 1
    파일 이름을 index.html로 저장:
    오른쪽 코드 화면의 전체 코드를 복사하거나 다운로드하여 index.html 이름으로 저장합니다.
  2. 2
    GitHub 새 저장소(Repository)에 업로드:
    GitHub에서 새 저장소(예: hyo-app)를 Public으로 만들고, 방금 저장한 index.html 파일 1개만 업로드(Add file → Upload files) 후 Commit 합니다.
  3. 3
    Settings → Pages 켜기:
    저장소 상단 [Settings] → 왼쪽 [Pages] → Branch를 main으로 선택 후 [Save]를 누르면 1분 뒤 https://아이디.github.io/hyo-app/ 링크가 완성됩니다!

스마트폰 홈 화면에 '찍어봐孝' 앱 아이콘 추가하는 법

• 갤럭시(안드로이드): 크롬이나 삼성 인터넷으로 깃허브 링크 접속 → 메뉴(점 3개 또는 줄 3개) → [홈 화면에 추가] 또는 [앱 설치] 터치!
• 아이폰(iOS): 사파리(Safari)로 링크 접속 → 하단 가운데 [공유(네모 화살표)] 버튼 → [홈 화면에 추가] 터치!
